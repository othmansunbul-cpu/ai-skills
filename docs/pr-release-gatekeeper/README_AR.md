# PR Release Gatekeeper

إعداد وصيانة: Othman Sunbul — عثمان سنبل  
[https://othmansunbul.com](https://othmansunbul.com)

تراجع مهارة PR Release Gatekeeper مسودة البيان الصحفي في ضوء الأدلة التي تقدّمها. وتبيّن ما تسنده هذه الأدلة، وما يحتاج إلى تصحيح أو تأكيد، وما ينبغي عرضه على شخص مخوّل قبل قرار النشر.

قدّم المسودة والمواد الداعمة، مثل مراجع الوقائع المعتمدة وحزمة الرسائل ودليل التحرير. تقتصر المراجعة على المواد التي تقدّمها ويمكن للمهارة قراءتها؛ ولا تبحث في الويب المفتوح من تلقاء نفسها.

للمراجعة الشاملة لجاهزية النشر (`FULL_GATE_REVIEW`)، يلزم نص مقروء ومصدر داعم صالح واحد على الأقل. ولسؤال محدد، استخدم مراجعة محددة النطاق (`FOCUSED_REVIEW`)، كسلامة الوقائع أو اتساق الرسائل أو الالتزام بدليل الأسلوب. ولا تصدر هذه المراجعة حكمًا شاملًا بجاهزية النشر.

تقدّم المهارة نتيجة منظّمة يجري التحقق من بنيتها، وملخصًا واضحًا يبيّن القرار حيث يسمح نطاق المراجعة، والنتائج بحسب أولويتها، وأدلتها، والمسائل التي تحتاج إلى مراجعة بشرية، وحدود الفحص. تعني المراجعة البشرية الحاجة إلى حكم شخص مخوّل أو إلى أدلة إضافية، وليست موافقة تلقائية. ولا تعيد المهارة كتابة البيان تلقائيًا، ولا تضمن خلوه من مخاطر النشر.

**التثبيت:**

```sh
npx skills add othmansunbul-cpu/ai-skills --skill pr-release-gatekeeper
```

يجب أن تتيح بيئة التشغيل قراءة الملفات المقدّمة وتشغيل `scripts/validate_result.py` من جذر المهارة المثبتة باستخدام Python 3 و`jsonschema==4.26.0` (راجع `requirements.txt`). مثال:

```text
<python-3-command> <skill-root>/scripts/validate_result.py <result.json>
```

تتحدد طريقة معالجة البيانات وفق بيئة التشغيل التي تستخدمها؛ فلا تقدّم إلا مواد يحق لك مشاركتها. راجع [القيود المعروفة](KNOWN_LIMITATIONS_AR_EN.md) و[صيغ مقترحة للاستخدام](SUGGESTED_PROMPTS_AR_EN.md). المهارة [متاحة عبر skills.sh](https://skills.sh/othmansunbul-cpu/ai-skills/pr-release-gatekeeper).
