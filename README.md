This public repository collects professional [Agent Skills](https://agentskills.io). Its first skill is **PR Release Gatekeeper**, which reviews a supplied press-release draft against supplied evidence before a human publication decision.

| Skill | Documentation |
|---|---|
| [PR Release Gatekeeper](skills/pr-release-gatekeeper/SKILL.md) | [English](docs/pr-release-gatekeeper/README_EN.md) · [العربية](docs/pr-release-gatekeeper/README_AR.md) · [Known limitations](docs/pr-release-gatekeeper/KNOWN_LIMITATIONS_AR_EN.md) · [Suggested prompts](docs/pr-release-gatekeeper/SUGGESTED_PROMPTS_AR_EN.md) |

**Install:**

```sh
npx skills add othmansunbul-cpu/ai-skills --skill pr-release-gatekeeper
```

The skill requires a host that can read supplied material and run its bundled Python validator. See the skill documentation for requirements. The public installation is available through [skills.sh](https://skills.sh/othmansunbul-cpu/ai-skills/pr-release-gatekeeper). Licensed under the [MIT License](LICENSE).
