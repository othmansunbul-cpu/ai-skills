# مهارات الذكاء الاصطناعي — Othman Sunbul AI Skills

إعداد وصيانة: Othman Sunbul — عثمان سنبل  
[https://othmansunbul.com](https://othmansunbul.com)

يضم هذا المستودع العام مهارات مهنية وفق صيغة [Agent Skills](https://agentskills.io). أولى مهاراته **PR Release Gatekeeper**؛ تراجع مسودة بيان صحفي في ضوء الأدلة التي تقدّمها، وتبيّن ما تسنده تلك الأدلة وما يحتاج إلى تصحيح أو مراجعة بشرية قبل قرار النشر.

اقرأ [دليل المهارة بالعربية](docs/pr-release-gatekeeper/README_AR.md) أو [بالإنجليزية](docs/pr-release-gatekeeper/README_EN.md)، واطّلع على [القيود المعروفة](docs/pr-release-gatekeeper/KNOWN_LIMITATIONS_AR_EN.md) و[صيغ مقترحة للاستخدام](docs/pr-release-gatekeeper/SUGGESTED_PROMPTS_AR_EN.md).

**التثبيت:**

```sh
npx skills add othmansunbul-cpu/ai-skills --skill pr-release-gatekeeper
```

تحتاج المهارة إلى بيئة تستطيع قراءة المواد المقدّمة وتشغيل المدقّق المرفق بلغة Python. وهي [متاحة عبر skills.sh](https://skills.sh/othmansunbul-cpu/ai-skills/pr-release-gatekeeper)، وتخضع لـ[رخصة MIT](LICENSE).
