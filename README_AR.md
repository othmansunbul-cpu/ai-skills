# مهارات الذكاء الاصطناعي — Othman Sunbul AI Skills

إعداد وصيانة: Othman Sunbul — عثمان سنبل  
[https://othmansunbul.com](https://othmansunbul.com)

هذه نسخة مرشحة قبل إنشاء مستودع GitHub، أُعدّت لتضم مهارات مهنية وفق صيغة [Agent Skills](https://agentskills.io). أول مهارة فيه هي **PR Release Gatekeeper**، لمراجعة مسودة بيان صحفي مقابل الأدلة المقدّمة قبل أن يتخذ شخص مخوّل قرار النشر.

اقرأ [دليل المهارة بالعربية](docs/pr-release-gatekeeper/README_AR.md) أو [بالإنجليزية](docs/pr-release-gatekeeper/README_EN.md)، وراجع [القيود المعروفة](docs/pr-release-gatekeeper/KNOWN_LIMITATIONS_AR_EN.md) و[المطالبات المقترحة](docs/pr-release-gatekeeper/SUGGESTED_PROMPTS_AR_EN.md).

**أمر التثبيت المخطط له، صالح بعد نشر المستودع على GitHub:**

```sh
npx skills add othmansunbul-cpu/ai-skills --skill pr-release-gatekeeper
```

تحتاج المهارة إلى مضيف يستطيع قراءة المواد المقدّمة وتشغيل المدقّق المرفق بلغة Python. لم يُنشر المستودع بعد، ولم يُختبر التثبيت البعيد أو التحقق من ظهوره على skills.sh. صدر المحتوى وفق [رخصة MIT](LICENSE).
