# PR Release Gatekeeper

إعداد وصيانة: Othman Sunbul — عثمان سنبل  
[https://othmansunbul.com](https://othmansunbul.com)

يساعد PR Release Gatekeeper فرق الاتصال على مراجعة مسودة بيان صحفي مقابل الأدلة التي تقدمها قبل اتخاذ قرار النشر. يبيّن ما تدعمه المراجع، وما يحتاج إلى تصحيح أو تأكيد، وما يتطلب قرارًا بشريًا.

استخدمه مع مسودة ومستندات داعمة مناسبة، مثل مراجع الوقائع المعتمدة وحزمة الرسائل ودليل التحرير. يعتمد على المواد المقدّمة التي يمكن الوصول إليها، ولا يبحث ذاتيًا في الويب المفتوح.

اختر **المراجعة الشاملة** (`Full Gate Review`) لفحص كامل للجاهزية للنشر. تحتاج إلى مسودة مقروءة ومصدر داعم واحد صالح على الأقل. واختر **المراجعة المركّزة** (`Focused Review`) لفحص سؤال محدد بوضوح، مثل سلامة الوقائع أو اتساق الرسائل أو الالتزام بدليل الأسلوب. لا تصدر المراجعة المركّزة حكمًا شاملًا بجاهزية النشر.

ستحصل على نتيجة مرجعية موحّدة جرى التحقق منها وملخص مقروء: القرار حيث يسمح نطاق المراجعة، والنتائج المرتبة، وروابط الأدلة، ومسائل المراجعة البشرية، وحدود الفحص. المراجعة البشرية تتطلب شخصًا مخوّلًا أو أدلة إضافية؛ ولا تعني موافقة تلقائية. لا يعيد المنتج كتابة البيان تلقائيًا ولا يضمن سلامة النشر من كل خطر.

بعد نشر مستودع GitHub المخطط له، يكون أمر التثبيت:

```sh
npx skills add othmansunbul-cpu/ai-skills --skill pr-release-gatekeeper
```

يجب أن يستطيع المضيف قراءة الملفات المقدّمة وتشغيل `scripts/validate_result.py` من جذر المهارة المثبتة باستخدام Python 3 مع `jsonschema==4.26.0` (راجع `requirements.txt`). مثال:

```text
<python-3-command> <skill-root>/scripts/validate_result.py <result.json>
```

تعتمد معالجة البيانات على المضيف الذي تختاره؛ لا تشارك إلا موادًا لديك إذن بتقديمها. راجع [القيود المعروفة](KNOWN_LIMITATIONS_AR_EN.md) و[المطالبات المقترحة](SUGGESTED_PROMPTS_AR_EN.md). لم تُنشر نسخة التوزيع المرشحة قبل GitHub بعد، ولم يُختبر التثبيت البعيد أو التحقق من ظهورها على skills.sh.
