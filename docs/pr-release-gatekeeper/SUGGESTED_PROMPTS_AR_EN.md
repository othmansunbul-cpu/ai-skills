# Suggested prompts / مطالبات مقترحة

Attach the relevant documents with each request. Name the scope you want checked; a focused check is not a full publication-readiness decision.

| Use | English | العربية |
|---|---|---|
| Full review | Review this press release for publication readiness using the attached editorial guide, messaging pack, and factual references. Show the decision, findings, evidence, and items needing human review. | راجع هذا البيان للتحقق من جاهزيته للنشر باستخدام دليل التحرير وحزمة الرسائل ومراجع الوقائع المرفقة. اعرض القرار والنتائج والأدلة والمسائل التي تحتاج إلى مراجعة بشرية. |
| Factual integrity | Focus only on factual integrity in this draft against the attached approved references. Identify claims that need correction or confirmation. | ركّز فقط على سلامة الوقائع في هذه المسودة مقابل المراجع المعتمدة المرفقة. حدّد الادعاءات التي تحتاج إلى تصحيح أو تأكيد. |
| Messaging alignment | Focus only on alignment with the attached approved messaging pack. Note material omissions or departures and the evidence for each. | ركّز فقط على اتساق البيان مع حزمة الرسائل المعتمدة المرفقة. بيّن أي حذف أو خروج مؤثر وأدلته. |
| Style compliance | Focus only on compliance with the attached applicable style guide. Do not make a full publication-readiness decision. | ركّز فقط على الالتزام بدليل الأسلوب المنطبق المرفق. لا تُصدر حكمًا شاملًا بجاهزية النشر. |
| Arabic review | Review this Arabic press release against the attached Arabic source material and editorial guidance. Keep the findings and evidence clear in Arabic. | راجع هذا البيان العربي مقابل المواد المصدرية والتوجيهات التحريرية العربية المرفقة، واعرض النتائج والأدلة بوضوح باللغة العربية. |
| English review | Review this English press release against the attached approved facts, messaging, and editorial guidance. | راجع هذا البيان الإنجليزي مقابل الوقائع والرسائل والتوجيهات التحريرية المعتمدة المرفقة. |
| Cross-language review | Compare the Arabic and English draft passages with the attached approved wording. Flag meaning or attribution differences that need confirmation; do not assume an unavailable approved translation. | قارن مقاطع المسودة العربية والإنجليزية بالصياغة المعتمدة المرفقة. بيّن اختلافات المعنى أو الإسناد التي تحتاج إلى تأكيد، ولا تفترض وجود ترجمة معتمدة غير مقدّمة. |
